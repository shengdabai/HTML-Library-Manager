# HTML 资料库管理器

找到本机 HTML，用主题短句识别内容，再搜索和打开原文件；本机管理器模式下还可以直接编辑页面、标注后交给本机 Codex 修改。macOS + Python 3.10+，运行时没有第三方依赖。扫描和搜索不修改源 HTML；只有你在编辑器里点保存或 Codex 任务写回时才改原文件，改之前都会先备份。不上传。

## 两种入口

- **静态 HTML 目录**：双击导出的 HTML 即可使用。支持全文搜索、目录筛选、排序、分页、收藏和最近打开。点击在浏览器打开原文件。它不自动发现后续文件变化；双击项目里的 `更新静态目录.command` 重新扫描，并原地刷新 `16-飞书HTML/00-HTML资料库管理器.html`（置顶文件，先写临时文件、fsync 后原子替换）。置顶文件只收录 `16-飞书HTML` 本身（约 1,400 页、25 MB，手机可开）；全库检索用 `启动本机管理器.command`。资料目录下的第一层子目录当作“主题文件夹”，工具栏可按主题筛选，卡片上显示所在主题；默认按最近修改排序，最新在前。导出包含本机路径及搜索用正文，请只在本人设备使用。
- **可选本机管理器**：双击 `启动本机管理器.command`。打开 `http://127.0.0.1:18455`。它扫描资料目录，可点击刷新并添加目录；源文件由 macOS 打开，保留相对资源。关闭终端或按 Ctrl+C 停止服务。没有安装登录启动，也没有公开网络部署。首次可能需要在 Finder 的“打开”确认脚本运行。端口被其他应用占用时报告错误，不终止其他应用。

原始语音中“取消本机部署”的含义待确认。静态目录交付不依赖服务；持久部署和登录启动不在本轮自动执行。

## 使用

1. 输入关键词。可以匹配主题短句、标题、文件名和提取的正文；多个关键词同时匹配。
2. 点击 `打开 HTML` 查看原文。点击 ☆ 收藏。使用“我的收藏”和“最近打开”查找常用页面。
3. 通过资料目录筛选来源。使用“扫描范围”核对成功、未读取和部分扫描。
4. 本机服务模式下，点击“资料目录”，每行填写一个本机路径，再保存扫描。静态模式只查看已扫描的目录。
5. 文件移动或删除后刷新索引；静态目录需要重新生成。打开原 HTML 会运行原页面自己的脚本并按它的规则加载外部资源。

默认扫描：HTML 报告归档优先，然后文稿、下载、桌面，最后单独扫描项目开发目录。不是整盘无遗漏扫描；资料盘需在本机模式显式添加，也可以用 `--root` 指定。隐藏、敏感、符号链接、依赖、构建、缓存和管理器源码目录跳过。每次最多 60 秒、150000 项、12000 页、4000 万正文字符；每个目录最多50000项；每 HTML 最多提取4 MiB / 前10万正文字符，大文件仍可打开并标注部分索引。状态显示上限与读取失败；缓存尚未复核会标明。

主题短句按页面标题 → 小标题 → 文件名提取，最长20字符。展示主题依据与原文件名。它是可追溯的主题提取，不是联网 AI 总结。相同 SHA-256 只提示“相同内容”，不删除文件。

收藏与打开记录：本机服务保存于 `~/.local/share/html-manager/`；静态模式保存于当前浏览器 localStorage，两种模式不共享收藏。扫描、检索不使用在线 AI；默认桌面导出包含目录与提取正文，并通过本人桌面同步到 iCloud。请勿对外分享。桌面同步不代替独立备份。云端占位文件只索引文件名，不主动读取正文；点击打开时系统可能下载原件。

## 在管理器里编辑（本机管理器模式）

资料卡片上点「编辑」，打开编辑工作台（`/edit?id=…`）。

- **改文字**：默认模式。直接在页面上点进去改错字；工具栏可以加粗、斜体、下划线、删除线、标题 H1–H3、列表、对齐、字色/底色、链接、清除格式。粘贴只保留纯文字。⌘Z / ⇧⌘Z 撤销重做，⌘S 保存。
- **选元素**：点页面上的任意块，右侧「元素」页可改字号、颜色、间距、宽度、对齐等样式，上移/下移/复制/删除/隐藏，或直接改这一块的 HTML。选中图片可改 alt、换成本机图片（png/jpeg/gif/webp，存进 `<页面名>_assets/`）。
- **标注**：点「＋ 标注」或在元素页「加标注」，在页面旁写下要改什么（文字/排版/图片/其他）。标注存在管理器状态目录，不写进页面。
- **交给 Codex**：在「Codex」页勾选标注、写整体要求，点「开始修改」。管理器把页面复制到隔离目录，后台运行本机 `codex exec`（workspace-write 沙箱），改文字、调排版、生成或修改图片都可以；完成后核对原文件没被别人改过，先备份再写回，并把新图片放进 `<页面名>_assets/`。运行期间编辑器锁定；可随时停止；不满意点「撤销这次修改」。真实冒烟：文字改写 + 生图一次约 4–5 分钟。
- **版本**：每次保存、恢复、Codex 写回或撤销前都备份原文件（每页保留最近 60 份），「版本」页可一键恢复。
- **冲突保护**：编辑期间原文件被其他程序改过时，保存会被拒绝，提示复制你的版本或重新载入，不会覆盖。

已知限制：编辑视图不运行页面脚本，脚本生成的内容看不到（脚本代码本身原样保留）；保存时浏览器会规范化 DOM（例如补上 `tbody`、统一属性引号），可能和手写源码有格式差异；换图时图片在上传那一刻就写进 `_assets/`，没点保存也会留下文件；非 UTF-8 或超过 20 MB 的页面只读；Codex 命令找不到时可设 `HTML_MANAGER_CODEX=/绝对路径/codex`。编辑视图会照常加载页面自己引用的远程图片、样式和字体（脚本和网络请求被禁止）；交给 Codex 时，页面片段和标注会随提示词发给你 Codex 账号对应的模型服务。Codex 改完后如果你又保存过，就不能直接「撤销这次修改」，请到「版本」页选具体备份恢复。

编辑相关的状态在 `~/.local/share/html-manager/editor/`（版本备份、标注、Codex 任务目录与日志）。

## 命令与测试

```sh
python3 manager.py --help
python3 manager.py scan --root /绝对路径/资料目录
python3 manager.py export --root /绝对路径/资料目录 --out /绝对路径/新目录.html
./更新静态目录.command   # 原地刷新置顶目录（内部：export --root 16-飞书HTML --state-dir ~/.local/share/html-manager/pinned-16 --out .../00-HTML资料库管理器.html --force）；默认不打开浏览器
./更新静态目录.command --open   # 刷新后在浏览器打开置顶目录（仅手动查看时用，Agent 收尾不要加）
python3 manager.py serve --port 18455 --open
python3 -m unittest -v test_library.py test_manager.py test_editor.py test_portable.py
export PLAYWRIGHT_MODULE=/opt/homebrew/lib/node_modules/playwright/index.mjs  # 本机已装 Playwright 1.57.0
node test_browser.mjs
node test_mobile.mjs
node test_editor_browser.mjs
```

三个浏览器脚本都启动 `~/.local/bin/chrome-headless-shell`（用 `CHROME_HEADLESS_SHELL` 可换路径），不用 Playwright 自带指定的 Chromium 版本。原因：每个 Playwright 版本只认一个固定的 Chromium 版本（1.57.0 认 `chromium_headless_shell-1200`），而本机缓存里是 1208 到 1234，直接 `chromium.launch()` 会报 `Executable doesn't exist`；该包装脚本会选缓存里最新的 headless shell。`test_mobile.mjs` 的 WebKit 部分需要与已装 Playwright 完全对应的 WebKit 版本（1.57.0 要 `webkit-2227`，缓存里只有 `webkit-2287`）；缺失时输出 `WEBKIT NOT INSTALLED - NOT RUN`，汇总行标注 `WEBKIT UNVERIFIED`，这不算通过。设 `REQUIRE_WEBKIT=1` 时缺失 WebKit 会让测试失败退出。

浏览器测试使用明确的临时资料与临时服务，不扫描真实资料。默认不真的调用系统打开：测试服务记录 `/usr/bin/open` 的参数并核对，不会弹出浏览器；测试结束自动删除测试目录。需要肉眼核验时设 `HTML_MANAGER_NATIVE_OPEN=1`，这时会真的打开一个无脚本的测试 HTML 并保留测试目录，核验后手动移入废纸篓。测试停止自己创建的服务。

## 维护与恢复

模块和边界见 `docs/TECH.md`；需求和验收见 `docs/PRD.md`；执行证据见 `.omc/plans/html-manager-todo.md` 和 `.omc/VALIDATION.md`；审核见 `.omc/cc-review.md` 与 `.omc/nlpm-review.md`。项目没有自动初始化 Git。修改前用 `ai-file-checkpoint` 保存明确文件；恢复到新的不存在目录，核对后再决定替换。没有源文件删除功能。

启动时会按当前扫描排除规则过滤旧缓存，避免依赖目录、隐藏路径或符号链接记录重新出现在搜索中。显式选择的资料根目录仍可单独扫描。资料目录配置格式错误时使用默认目录；任务记录格式错误时跳过该任务并保留记录文件；版本索引格式错误或版本名称含路径时忽略对应条目，保存仍须先备份当前页面。正文提取会处理文件末尾尚未闭合的文本和字符实体。

不含登录/支付、云端 AI 总结、运行页面脚本的预览、源文件删除或无人值守服务。编辑测试用假 Codex，不调用真实模型；浏览器编辑测试默认使用 `~/.local/bin/chrome-headless-shell`（可用 `CHROME_HEADLESS_SHELL` 指定）。三条本人真实使用记录待使用后填写，机器测试不等于本人使用体验或付费需求。

## 2026-10-08 手机离线搜索修复

导出文件自包含搜索所需的已提取正文索引。在执行 JavaScript 的浏览器 / 本地 HTML 阅读器中，电脑和手机均可离线搜索；不需要电脑服务。iPhone“文件”和飞书内的预览可能不执行 JavaScript，无法由 HTML 强制启用。在这种预览中使用附带的完整文字目录和查看器的“查找”，范围仅主题、标题、文件名和摘要；没有原生查找功能的查看器只能手动浏览。全文筛选需要换成支持脚本的打开方式。实际 iPhone 预览尚未实机验收。

新增“仅标题与文件名”和清空搜索。全文多关键词按 AND 匹配；离线模式支持 NFKC 全角归一化。预先归一化文本、排序和重复计数，后台 Worker 搜索；Worker 被禁时用分片异步搜索，浏览器存储被禁时仍可搜索。中文输入法组词结束后才检索，旧请求不会覆盖新结果。结果缓存上限 8 个查询。页内显示本次索引查询时间，包含过滤，不包含输入等待和页面绘制。

单独下载目录不包含原 HTML 文件。手机不能访问电脑的 file:// 路径；在手机“文件”里按原文件名寻找另外下载的原件。收藏和最近打开按浏览器保留，不能跨设备同步。文件含本人路径与正文索引，不分享给他人。扫描上限、缺失文件和索引截断仍以“扫描范围”标记为准。

回归检查：`python3 -m unittest -v test_library.py test_manager.py test_portable.py`；`PLAYWRIGHT_MODULE=/opt/homebrew/lib/node_modules/playwright/index.mjs node test_mobile.mjs`（Chromium 走 `~/.local/bin/chrome-headless-shell`，WebKit 缺失时标注未验证，见上文「命令与测试」）。手机回归使用合成样例，在 Chromium 与 WebKit 校验离线导出、全角/正文/标题搜索、占位符安全、输入法、Worker 错误回退、禁存储与禁脚本降级。测试样例默认由测试进程退出时在本地删除,只断言 Trash 调用的命令与参数、不写真实废纸篓;设 `TEST_MOBILE_REAL_TRASH=1` 才经 macOS 原生 Trash API 清理。
