# Architecture and trust boundaries

Shared index: library.py extracts local HTML metadata without executing markup. UI consumes untrusted fields as text. Label is an extractive topic, not an AI-generated conclusion.

Delivery modes: standalone file catalog can be generated with embedded metadata and file: links; automatic discovery/refresh and reliable source-open use an optional loopback service. Deployment selection pending; test service is temporary only. No login startup installation.

Local runtime (if selected): Python standard library threaded HTTP server on 127.0.0.1, random per-run CSRF token, exact Host/Origin enforcement, bounded POST size, indexed IDs only, macOS /usr/bin/open argument list. Library pages never render source HTML. The editor (`/edit`, editor.py) is the only exception: `/p/<id>/<relative>` serves the indexed page and its relative assets (the lexical path is checked with `allowed_path` before resolving, so symlink components are refused; the resolved path must stay inside the page's indexed source root, extension allow-list, no symlink page) with CSP `script-src 'none'; connect-src 'none'; form-action 'none'` and the editor embeds it in a same-origin iframe with `sandbox="allow-same-origin"` (no allow-scripts), so page scripts never run while the parent edits the DOM via designMode. Editor writes: version backup → atomic write → reindex; base SHA-256 mismatch → 409. Codex jobs run `codex exec -s workspace-write -c approval_policy="never"` in `state/editor/jobs/<id>/work` (copy of the page plus `<stem>_assets/`), at most 2 concurrent, 25-minute timeout, process-group kill on cancel; results are applied only when the original digest is unchanged. Writes back-up the verified bytes and re-check them immediately before the atomic rename; an outside writer can still race the final instant (closing that needs a shared lock). Undo of a Codex job requires the page to still hold that job's output. Annotation status `sent` is owned by the server (frozen while a job runs, reverts to `open` when no job holds it). Codex assets are copied only when `<stem>_assets` has no symlink component, with exclusive create (existing names, including dangling links, are skipped). Uploads accept png/jpeg/gif/webp by magic bytes (no SVG), 12 MB. CSP restricts connections to same origin. Metadata and favorites remain in local state storage. The manager makes no outside network calls (see the editor network boundary below).

Network boundary: the manager itself makes no outside calls, but the editor preview still lets the page load its own remote images, stylesheets, fonts and frames (scripts, fetch/XHR and form posts are blocked). Codex jobs run the local Codex CLI, which sends the prompt (page excerpts and annotations) to its model provider under the owner's Codex account.

Sources: prioritize personal report archive, Documents/Downloads/Desktop plus a separate final development root. Optional user-selected roots within home or mounted user /Volumes. Hidden/sensitive/symlink/dependency/build/cache directories excluded. Index scan time/file/entry caps are reported; unavailable roots and extraction errors remain visible. read at most 4 MiB per file and retain large files with partial-text flags, 100k text chars. Partial scans must not silently erase previously indexed entries; use report.partial and preserve unvisited records.

Persistence: atomic JSON catalog and favorites/recent state. Project remains non-Git; explicit checkpoints before revisions.

Spike: browser cannot auto-scan disk from a plain file; verify portable file links with headless file-based navigation. Verify native open for original HTML retains relative resources. Both are explicit limitations, never mock as deployed.
